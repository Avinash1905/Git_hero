# GitHero

> Master Git by Changing the World.

GitHero is a tactile 2D command-line puzzle adventure blending the precision of a terminal with interactive puzzle mechanics across 250 handcrafted levels.

## Overview

- **Core Gameplay**: Control your hero avatar using keyboard arrow keys, on-screen controls, or direct terminal movement commands (`git up`, `git down`, `git left`, `git right`).
- **Git Plumbed**: Execute authentic Git commands (`git status`, `git push`, `git pull`, `git commit`, `git switch`) to manipulate repository objects and stage commit payloads.
- **Progression**: 250 numerical sectors across 20 themed worlds, with strict sequential progression and real backend authentication.

## Quick Start

```bash
# Install dependencies
npm install

# Start production server
npm start
```

Open `http://localhost:3000` to play GitHero.
